CHRONOSPARK SMART COACH SCREEN AUDIT
Date: 2026-08-01
Scope: In-depth audit of Emotional State, Focus Context, Adaptive Replan, Recurring Patterns, and Goal Success Forecast sections.
File audited: lib/features/home/ui/smart_coach_screen.dart

FINDINGS (ordered by severity)

[High] Goal Success Forecast has a likely placeholder/defect in UI output
- Location: goal forecast block uses a standalone percent marker text line.
- Evidence: const Text('%') appears between the section title and summary content.
- Impact: The card can render confusing output (a lone "%") that looks broken or unfinished and reduces trust in forecast quality.
- Why this matters: This is user-facing in a strategic section; low polish here harms perceived model quality.
- Recommendation: Replace the standalone percent marker with meaningful metric text (for example a computed confidence label) or remove it if redundant.

[Medium] Adaptive Replan suppresses scenario breadth by rendering only the first scenario and top 3 moves
- Location: _AdaptiveReplanningPanel
- Evidence:
  - final AdaptiveReplanningScenario scenario = scenarios.first;
  - ...scenario.moves.take(3)
- Impact: Users may miss better or more relevant alternatives when multiple scenarios exist.
- Why this matters: Replanning is a high-value surface; over-aggressive truncation can reduce action quality and explainability.
- Recommendation: Consider rotating or exposing additional scenarios/moves via compact expansion affordance while keeping current default compact view.

[Medium] Recurring Patterns panel visual hierarchy is inconsistent with surrounding premium cards
- Location: _MemoryPatternsPanel
- Evidence: Container has only borderRadius in decoration, with no explicit card background, border, or contrast treatment unlike nearby panels.
- Impact: Section can look visually detached or under-emphasized, making recurring insights easier to ignore.
- Why this matters: Pattern recognition is core to behavioral improvement; weak visual hierarchy can reduce engagement.
- Recommendation: Align this block's visual treatment with neighboring coach panels (subtle dark fill + light border), preserving current data/logic.

[Low] Focus Context field compacting improves density but may reduce short-form editing comfort for longer notes
- Location: FOCUS CONTEXT panel text field
- Evidence: maxLines is 3.
- Impact: Not a logic defect; users writing longer context may need more scrolling inside field.
- Why this matters: Rich context quality directly affects coaching quality.
- Recommendation: Keep current compact setting if product prefers density; otherwise allow dynamic growth up to 4 lines for better long-note ergonomics.

[Low] Emotional State panel behavior is solid but has no explicit helper copy
- Location: EMOTIONAL STATE panel with EmotionSelector
- Evidence: Selector is present and updates both local UI state and provider state; no explanatory microcopy.
- Impact: New users may not understand how this setting affects recommendations.
- Why this matters: Better understanding generally increases deliberate usage.
- Recommendation: Optional one-line helper text under selector if UX wants stronger onboarding clarity.
