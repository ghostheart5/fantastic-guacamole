2. Every old progression formula found
- ProfileController.addXP(): level = (newXP ~/ 50) + 1
- ProgressionEntity.addXp(): cumulative threshold while-loop using 50 XP bands
- ProfileEntity.addXp(): cumulative threshold while-loop using 100 XP bands
- ProgressionPolicy.levelFromXp(): floor(sqrt(xp / 100)) + 1
- ProgressionPolicy.xpForLevel() / UserProgress helpers: banded policy math based on ProgressionPolicy

3. Canonical formula selected
- ProgressionPolicy.levelFromXp(xp)

4. Why ProgressionPolicy was selected
- ProgressionPolicy is the only place with the documented level model.
- UserProgress derives xpToNext and levelProgress from ProgressionPolicy.
- The Progression screen consumes UserProgress, so its visible math already depends on ProgressionPolicy.
- This makes ProgressionPolicy the clearest canonical source for XP-to-level calculation.

5. Whether ProfileController.addXP now uses ProgressionPolicy
- Yes.
- It now computes level with ProgressionPolicy.levelFromXp(newXP).

6. Whether ProgressionEntity.addXp now uses ProgressionPolicy
- Yes.
- It now computes level with ProgressionPolicy.levelFromXp(newXp).
- The old threshold while-loop was removed.
