WEEKLY CRASH TRIAGE CHECKLIST

Week of:
Owner:

1) Intake
- [ ] Pull top fatal crashes from Crashlytics for last 7 days
- [ ] Pull top non-fatal error categories for last 7 days
- [ ] Confirm no secrets are present in logged error payloads

2) Classification
- [ ] Label each issue Sev-1, Sev-2, or Sev-3
- [ ] Mark reproducible vs non-reproducible
- [ ] Identify platform scope (Android, iOS, Web, Desktop)

3) Assignment
- [ ] Assign owner for each Sev-1 issue
- [ ] Set ETA for fix or mitigation
- [ ] Link ticket/PR for each Sev-1 and Sev-2 issue

4) Mitigation
- [ ] Define immediate mitigation for open Sev-1 issues
- [ ] Add runtime guard or fallback if full fix is not ready
- [ ] Confirm user-facing impact statement is documented

5) Validation
- [ ] Run targeted tests for impacted subsystem
- [ ] Run crash observability verifier script
- [ ] Confirm fix evidence in logs/Crashlytics after deployment

6) Release impact statement
- [ ] Buildable status: Yes / No
- [ ] Play-ready status: Yes / No
- [ ] Go / No-Go recommendation recorded
