SECTION 14
TARGET AUDIO SYSTEM
============================================================

Design strategy:
- Keep SFX brief, low-volume, semantically distinct, and optionally disableable.
- Prioritize completion confidence and error clarity over novelty.
- Ship changes in small, reversible phases to protect focus and avoid alert fatigue.
- Default to quiet-first behavior with explicit opt-in for richer feedback.

Cue map:
- Create Sound:
  when: explicit user-confirmed create action succeeds (task/goal/routine/note)
  character: soft upward tick, 120-220 ms

- Complete Sound:
  when: task completion confirmed and persisted
  character: clean resolved chime, 180-280 ms

- Skip Sound:
  when: skip action confirmed
  character: neutral downward tap, 120-180 ms

- Progress Sound:
  when: level-up/milestone/streak threshold reached
  character: compact premium swell, <= 450 ms, strict cooldown

- Error Sound:
  when: validation or failed action requiring user correction
  character: soft muted knock, 100-180 ms

- Reminder Sound:
  when: scheduled reminder fires in foreground handling path
  character: calm ping, distinct from completion cue

- Haptic Feedback:
  when:
  - create success: light impact
  - completion: medium impact
  - error: warning vibration
  - milestone: medium impact + short celebratory pulse
  constraints: never fire repeatedly in rapid sequences

Safe rollout architecture:
- Phase A (low risk):
  - Keep existing completion and milestone cues.
  - Add error cue mapping only for explicit validation failures.
  - No new background audio, no music layer.

- Phase B (controlled expansion):
  - Add distinct create cue and skip cue with strict cooldown.
  - Add minimal haptic layer for completion and validation error.
  - Keep reminder sound conservative and category-aware.

- Phase C (optional premium layer):
  - Add advanced optional audio profile for users who want richer reinforcement.
  - Keep default profile subtle and productivity-first.

Safety gates per phase:
- Gate 1: focus protection
  - No event may trigger more than one SFX and one haptic pulse at once.
- Gate 2: anti-fatigue
  - Repeated events must obey cooldown windows.
- Gate 3: semantic clarity
  - Complete, skip, error, and reminder cues must be audibly distinct.
- Gate 4: user control
  - Respect existing sound enable/disable controls everywhere.

Rollback criteria:
- Increase in user-reported annoyance, distraction, or perceived noise.
- Any evidence of overlapping or stacked cues during normal task flow.
- Any mismatch between event meaning and sound identity.
