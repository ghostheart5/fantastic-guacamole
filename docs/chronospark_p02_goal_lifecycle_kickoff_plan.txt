2) TARGET LIFECYCLE CONTRACT (CANONICAL)
============================================================
Primary status contract
- active: user is working toward goal.
- completed: goal is achieved; completedAt set.
- archived: goal is out of active scope; archivedAt set.

Allowed transitions
- active -> completed
- active -> archived
- completed -> active (reopen/reactivate)
- completed -> archived
- archived -> active (restore)

Forbidden behavior
- complete must never delete.
- archive must never delete.
- delete is explicit destructive action only.

Timestamp rules
- On complete: completedAt is set to transition time if null.
- On archive: archivedAt is set to transition time if null.
- On reactivate/restore: status becomes active; keep historical timestamps for audit continuity unless product explicitly requires clearing.
