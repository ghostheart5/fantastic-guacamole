6) Exact PowerShell command to move safely
Use from repo root:

$stamp = Get-Date -Format 'yyyy-MM-dd'
$destRoot = "archive/feature_backups/lib_features_$stamp"
$repoRoot = (Resolve-Path .).Path
$srcRoot = Join-Path $repoRoot 'lib/features'
$files = Get-ChildItem -Path $srcRoot -Recurse -File | Where-Object { $_.Name -like '*.bak*' }
foreach ($f in $files) {
  $relative = $f.FullName.Substring($srcRoot.Length).TrimStart('\\')
  $dest = Join-Path $destRoot $relative
  $destDir = Split-Path $dest -Parent
  New-Item -ItemType Directory -Path $destDir -Force | Out-Null
  Move-Item -Path $f.FullName -Destination $dest -Force
}

Notes:
- Preserves original folder structure under archive.
- No file content changes.
