Privacy PolicyLast updated: August 31, 2026

This policy describes the data ChronoSpark may process and the stricter feature containment applied to the current release candidate. A listed provider is not proof that every provider feature is enabled.

Information you provide

Account identifiers used for sign-in, such as an email address or sign-in provider identifier.Planning content you intentionally create, including tasks, planning context, goals, notes, schedules, preferences, and reflections.Support or account-deletion messages you choose to send.

Information needed for app functions

Authentication and security events needed to protect an account.Notification device tokens only when messaging features are initialized for notifications.Purchase or entitlement data only when a supported Google Play billing flow is used.Local diagnostics needed to display and recover from an error on the device.

Current release containment

External AIDisabled. The current release candidate does not send Planner content to an external generative-AI provider.

Cloud syncDisabled for the release candidate.

Cloud restoreDisabled for the release candidate.

Subscriptions and creditsDisabled for the release candidate.

AnalyticsDisabled by default and release-contained off.

Crash reportingDisabled by default and release-contained off. Raw account identifiers must not be attached to crash reports if this changes in a future release.

Local and backend storage

ChronoSpark stores data on the device so core planning functions can work locally. Account and security services may use Supabase for authentication and approved account-scoped backend operations. Features described as release-disabled above must not be treated as active merely because supporting code or a provider SDK exists.

Service providers

ChronoSpark may use Supabase for authentication and approved backend operations, Firebase Cloud Messaging for notifications, and Google Play for Android distribution and billing. Firebase Analytics and Crashlytics are release-contained off. Anthropic is the disclosed provider for a possible future external Planner explanation, but that feature is currently disabled and is not a public capability.

Retention and deletion

Account-linked information is retained only as needed to provide the active service, satisfy legal obligations, prevent fraud or abuse, resolve disputes, and protect security. Use the account-deletion page to review in-app and external request paths. Device-local data on an offline device may require clearing app storage or uninstalling the app.

Your choices

Control available notifications and privacy settings in the app.Request access, correction, or deletion of account-linked information.Do not send passwords, one-time codes, recovery tokens, payment details, or secret keys in a support request.

Security and policy changes

ChronoSpark uses technical and organizational safeguards appropriate to the service, but no system is completely secure. Material policy changes will be posted at this URL with an updated date.
