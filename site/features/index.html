Feature proof

A clear job for every surface.

ChronoSpark connects inputs, scheduled action, guidance, and reflection without turning every part of planning into an opaque automatic system.

01 / Nexus

Start with the operating view.

Nexus is the main and home surface. It brings connected planning state into view so you can orient before deciding what deserves attention.

  • Current connected state rather than a second task editor.
  • Clear handoff to the surface where the work belongs.
  • Partial or unavailable signals are treated as such.
Nexus / current context
Operating briefing — context available
Next commitment — plan deliberately
Connected inputs — tasks, goals, notes, Daily Rhythms
Creator / intentional inputs
Task — a specific action
Goal — an outcome to work toward
Note — context and reflection
Daily Rhythm — repeatable practice
02 / Creator + Timeline

Separate what you create from when you plan it.

Creator owns planning inputs. Timeline is the scheduling projection for actions you choose to plan and review. This keeps creation and scheduling clear.

  • Tasks, goals, notes, and Daily Rhythms begin in Creator.
  • A note remains context unless you deliberately create related work.
  • Timeline supports scheduled action; it is not another authoring system.
03 / Guidance

Use assistance without surrendering judgment.

Smart Planner offers planning guidance. SI Console is an explainable recommendation and decision surface for deeper investigation. Both are inputs to evaluate, not automatic authority.

  • Guidance works from the available context.
  • Important decisions still require user review.
  • Reflections and notes can support thinking without automatically becoming conclusions.
SI Console / explainable guidance

04 / Progression

Close the loop with reflection.

Progression focuses on evidence-backed advancement and leverage actions. Reflection captures what you learned so the next plan can become more deliberate.

  • Record context in Notes when it is useful.
  • Review outcomes instead of treating every signal as a verdict.
  • Adjust the next action, goal, or Daily Rhythm intentionally.
