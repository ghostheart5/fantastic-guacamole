# Phone screenshot capture gate

Prepared October 2, 2026 for intended public-profile candidate `4.2.3+2026083102`. No final-candidate captures or acceptance are supplied by this checklist. Older screenshot sets remain historical until their exact source and scope are reconciled.

Do not upload the existing files under `assets/screenshots/`. They show retired terminology and unsupported or invented claims, including Smart Coach, fixed personal scores, old Creator object types, and forecasting/premium surfaces.

## Required source

Capture screenshots only from Play-generated APKs produced from the exact signed release AAB selected as the candidate, after the separately authorized test-track delivery. Record the source commit, public configuration receipt, AAB SHA-256, installed package/version, device, Android version, locale, and capture time. Do not label a debug, private-profile, or older build as the final public candidate.

## Required format

- Project target: 4-8 portrait phone screenshots per prepared locale
- PNG or JPEG
- 1080 x 1920 or another compliant 9:16 size with at least 1080 px on each side for promotion eligibility
- Prepare English (en-US) and Spanish (es-419) sets to accompany the two listing drafts; verify localized labels on the same candidate. Listing locales do not authorize countries or rollout.
- no emulator chrome, PIN screen, notification shade, personal email, tester identity, secrets, or private user content
- no composited feature claims that are not visible in the exact app

## Proposed truthful sequence

1. Nexus with an honest insufficient-evidence or current-context state
2. Reality Builder / Constructor de Realidad with a task draft before confirmation
3. Reality Builder / Constructor de Realidad confirmation preview showing nothing saved yet
4. Truth Ledger / Registro de Verdad with scheduled time distinguished from a due date
5. Now Engine / Motor del Ahora guidance with evidence and assumptions visible
6. Deep Intelligence / Inteligencia Profunda with an actual read-only evidence response
7. Future Branches / Ramas Futuras with scenario assumptions visible
8. Settings with the actual optional Cloud Backup coverage and recovery limits visible; never expose a recovery key

Only capture AI, billing, or cloud states that the selected artifact actually supports and the acceptance record has verified. A screenshot is not purchase, deletion, recovery, or provider-handling evidence. Never simulate paid responses, balances, saved records, or successful service states.

## Acceptance

Every screenshot must be visually checked at full resolution for clipped text, tiny essential text, stale terminology, unsupported feature claims, fabricated personal precision, accessibility issues, and sensitive data before upload.

Record each accepted image's filename, SHA-256, dimensions, locale, visible feature, and reviewer disposition alongside its candidate identity. Keep all fields pending until observed. The completed image set still requires owner upload approval and exact Console readback; this checklist authorizes neither.
