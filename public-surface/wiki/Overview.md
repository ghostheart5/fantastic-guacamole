# Axiomara overview

> Guide updated October 23, 2026. Screen names can vary by installed version. The October 22–23 repairs are tested and merged; this does not establish that a new Google Play build is available. See [[Release Notes|Release-Notes]].

Axiomara connects planning, action and reflection. Capture a task, goal, habit or note; review it in My plan; use Schedule for time; record what happened; then explore Activity and Insights.

The comparison controls in Insights let you compare modeled outcomes while leaving saved records unchanged. AI and SI Chat can help examine a question using the context you select. Free tools are separate from quoted cloud questions; Settings is the reference for your account's credits and controls.

Start with [[Getting Started|Getting-Started]]. Use [[comparisons in Insights|Trajectory-Engine]] for comparisons, [[Chat|Smart-Planner]] for questions and [[Release Notes|Release-Notes]] to distinguish tested changes from public availability. A chart or response is guidance, not a guaranteed outcome.
