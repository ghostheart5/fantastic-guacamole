# A daily workflow

> Guide updated October 23, 2026. Screen names can vary by installed version. The October 22–23 repairs are tested and merged; this does not establish that a new Google Play build is available. See [[Release Notes|Release-Notes]].

1. Review **Today** and choose a manageable next step.
2. Use **Add something** for a task, goal, habit or note you actually need.
3. Review **My plan** and use **Schedule** for real dates and constraints.
4. Do the action, then record the real completion or habit progress.
5. Review **Activity** and **Insights** to understand the recorded pattern.
6. If useful, use **Insights → Compose a what-if path** to compare a possibility or **Chat** for a question. Review uncertainty, context and any credit quote.

You do not need to use every feature each day. Free tools remain distinct from paid cloud questions. Levels and streaks are feedback, not a measure of personal worth. A comparison never substitutes for doing or recording the real action.
