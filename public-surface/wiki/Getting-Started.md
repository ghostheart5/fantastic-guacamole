# Getting started

> Guide updated October 23, 2026. Screen names can vary by installed version. The October 22–23 repairs are tested and merged; this does not establish that a new Google Play build is available. See [[Release Notes|Release-Notes]].

## 1. Add one useful record

Choose **Add something**. Create a task you can finish, a goal you can work toward, a habit you want to repeat, or a note for useful context. Review the details and save. Optional guidance can be skipped; opening a guide does not create a record.

## 2. Make room in your day

Find the record in **My plan**. Use **Schedule** when a date, start time or deadline matters. A planned start and a hard deadline mean different things; check the date and time before saving. Do not invent a deadline just to make a forecast look complete.

## 3. Do the action and record the outcome

Use **Today** to choose a manageable step. Complete a task only after doing it; record habit progress honestly. Check the result in your plan and **Activity**. Simulation does not count as completing the real task.

## 4. Get help when useful

In **Chat**, select the context you want to share and ask a specific question. Free tools and cloud questions are separate. Review consent and the displayed credit quote before sending a paid question; you do not need a paid question to keep planning.

## 5. Compare a possibility

Open **Insights → Predictions** when available. Review the horizon, evidence and uncertainty. Select a task and an operation such as **Complete**, **Delay** or **Remove**, then press **Compare**. **View comparison** opens that calculated result. Changing an input requires a new comparison; it does not silently change your saved task.

Continue with [[Predictions|Trajectory-Engine]], [[Settings]] and [[Troubleshooting]].
