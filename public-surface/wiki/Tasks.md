# Tasks

A task is one concrete action to complete. Tasks turn an intention into work you can name, do, and review.

Tasks are created and managed in [[Creator]]. Use [[Timeline]] when an action needs to be scheduled or reviewed over time.

## How tasks differ from other items

- A [[Goals]] is an outcome you want to reach.
- A task is a specific action that can help move toward that outcome.
- A [[Daily Rhythms]] is a repeated practice.
- A [[Notes]] holds context, ideas, or reference material.

For example, “launch a website” is a goal. “Write the homepage outline” is a task.

## Create a useful task

- Start with an action-oriented title, such as “Send the project proposal.”
- Keep the action small enough to understand and begin.
- Add scheduling information only when it helps you plan the work.
- Break a larger outcome into a small set of clear next actions.

## Completion and review

Mark a task occurrence complete when that action is done. A completion record represents that completed occurrence; later Timeline, sync, or learning updates do not rewrite the fact that it was completed.

After a task is complete, use [[Nexus]], [[Smart Planner]], or [[SI Console]] to review the current context and decide what to do next. These surfaces provide orientation or guidance; they do not guarantee an outcome.
