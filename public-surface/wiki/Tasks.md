# Tasks

> Guide updated October 23, 2026. Screen names can vary by installed version. The October 22–23 repairs are tested and merged; this does not establish that a new Google Play build is available. See [[Release Notes|Release-Notes]].

A task is one concrete action to complete. Tasks turn an intention into work you can name, do, and review.

Tasks are created and managed in [[Add something|Creator]]. Use [[Schedule|Timeline]] when an action needs to be scheduled or reviewed over time.

## How tasks differ from other items

- A [[Goals|Goals]] is an outcome you want to reach.
- A task is a specific action that can help move toward that outcome.
- A [[habits|Daily Rhythms]] is a repeated practice.
- A [[Notes|Notes]] holds context, ideas, or reference material.

For example, “launch a website” is a goal. “Write the homepage outline” is a task.

## Create a useful task

- Start with an action-oriented title, such as “Send the project proposal.”
- Keep the action small enough to understand and begin.
- Add scheduling information only when it helps you plan the work.
- Break a larger outcome into a small set of clear next actions.

## Completion and review

Mark a task occurrence complete when that action is done. A completion record represents that completed occurrence; later Schedule, sync, or learning updates do not rewrite the fact that it was completed.

After a task is complete, use [[Today|Nexus]], [[Chat|Smart Planner]], or [[SI Chat|SI Console]] to review the current context and decide what to do next. These surfaces provide orientation or guidance; they do not guarantee an outcome.
