# Add something

> Guide updated October 23, 2026. Screen names can vary by installed version. The October 22–23 repairs are tested and merged; this does not establish that a new Google Play build is available. See [[Release Notes|Release-Notes]].

Create a task, goal, habit or note. Write enough context to make it useful, review the fields and save explicitly.

- **Task:** a concrete action you can complete. Add a start time or deadline only when it is real.
- **Goal:** an outcome you can work toward and review over time.
- **Habit:** a repeatable action; record its actual progress.
- **Note:** context or information worth keeping without turning it into an obligation.

Check the saved item in My plan. Opening guidance, previewing a comparison or reading a suggestion is not the same as saving or completing an item.
